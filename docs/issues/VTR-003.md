## What to build

Hand‑written OpenAPI 3.1 spec (`packages/api-contract/openapi.json`) covering all endpoints in `api.md`, including OCC headers, error schemas, and u64 fields as JSON numbers.

## TDD Instructions

This is a static spec – testing is validation:

1. **Install `openapi‑validator` (or use `swagger‑cli`)** and run validation against the written spec – must pass with zero errors.
2. **Write a contract test** (using `pact` or `openapi‑test`) that loads the spec and checks that at least one example request/response matches the schema.
3. **Manually review** that every endpoint has `If‑Match` header defined for mutable methods.

Implementation: produce the JSON file by hand, respecting the exact paths and schemas from `api.md`.

## Acceptance criteria

- [ ] `openapi-validator openapi.json` exits 0.
- [ ] All error codes (412, 410, 422, 429) are documented.
- [ ] The spec includes `x-vautr-min-client-version`.
