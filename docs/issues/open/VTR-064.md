## What to build

The extension is the thinnest client (server-backed vault access + generator +
MFA only). Bring it to parity with web:

- Conflict modal (VTR-056): subscribe to `ConflictDetected`, render dialog,
  resolve via client — the `packages/ui-logic` store already has the FIFO
  `conflictQueue` + `resolveConflict` machinery; reuse it.
- Import/export (VTR-039).
- Machine accounts + tokens (VTR-047 sidebar sections).

## Acceptance criteria

- [ ] Extension surfaces the conflict modal on `ConflictDetected`.
- [ ] Extension can import/export.
- [ ] Extension shows machine accounts + tokens.
