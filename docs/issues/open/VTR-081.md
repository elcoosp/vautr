# VTR-081 — Onboarding wizard crashes on register/login

## Problem
After register/login the first-run onboarding overlay threw:

```
[OnboardJS] Invalid Onboarding Configuration:
Step 'welcome' of type 'CUSTOM_COMPONENT' must have a 'componentKey' in its payload
Step 'create-vault' ... Step 'emergency-kit' ... Step 'add-secret' ... Step 'done' ...
```

`@onboardjs/react` rc.4's `StepValidator` requires `CUSTOM_COMPONENT` steps to
declare `payload.componentKey`, and the `OnboardingProvider` needs a matching
`componentRegistry`. The steps only passed `component:` directly, so the validator
rejected the whole flow and React rendered the red error screen.

(NOTE: this red error screen was what the user reported as "screen is red not
green emerald" — it is a separate cause from VTR-080's accent color.)

## Fix
- `apps/web/src/onboarding/steps.tsx`: added `payload: { componentKey: <id> }` to
  all five steps and exported `onboardingComponents` mapping each key → component.
- `apps/web/src/onboarding/OnboardingFlow.tsx`: passed
  `componentRegistry={onboardingComponents}` to `OnboardingProvider`.
  The renderer resolves `componentKey` against the registry, so steps render.

## Verification
- `apps/web` `tsc --noEmit` green (componentRegistry prop accepted).
- `pnpm build` green.
- `biome check --write` clean.
- `hermes verify --json` green.

## Acceptance
Register/login first-run onboarding renders the welcome → create-vault →
emergency-kit → add-secret → done flow with no OnboardJS error.
