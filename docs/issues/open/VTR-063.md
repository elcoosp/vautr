## What to build

Desktop drives the full local `vautr-app-state` orchestrator (vault list, secret
view, generator, MFA, quarantine reaper, and now the conflict modal from VTR-056),
but its GPUI surface is thin compared to web. Bring it to parity:

- Import/export (VTR-039): encrypted-archive import + encrypted/plaintext export.
- Machine accounts (VTR-047 sidebar section): list / create / rotate.
- Tokens (VTR-047 sidebar section): API token CRUD.
- Sharing / key rotation (VTR-020): UI to share an item and rotate a key.

The core methods already exist on `VautrClient`; this is GPUI view work only.

## Acceptance criteria

- [ ] Desktop can import + export an encrypted archive.
- [ ] Desktop shows machine accounts + tokens sections mirroring web.
- [ ] Desktop can share an item and trigger key rotation from the UI.
