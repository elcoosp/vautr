## What to build

An asynchronous function `register_user(server_url: &str, email: &str, password: Zeroizing<String>) -> Result<(), AuthError>` in `vautr-auth` that executes the OPAQUE client registration protocol against a server (mocked with `wiremock` in tests). Uses `opaque-ke` crate.

## TDD Instructions

1. **Write a test** that sets up a `wiremock` server expecting `POST /auth/register/start` and `POST /auth/register/finish` with valid OPAQUE messages; asserts registration returns `Ok(())`.
2. **Write a test** where the server returns 400 on the first endpoint; asserts `AuthError::InvalidCredentials`.
3. **Write a test** where the server returns malformed OPAQUE messages (invalid base64); asserts `AuthError::ProtocolError`.
4. **Write a test** that verifies the client never sends the master password in plaintext (inspect the mock requests – the password is only used inside OPAQUE state machine).

Implementation must handle request serialization, deserialization, and state machine transitions. The server URL is base + `/auth/...`.

## Acceptance criteria

- [ ] All tests pass.
- [ ] No hardcoded network timeouts – use configurable timeout.
- [ ] The function is `async` and uses `reqwest`.
