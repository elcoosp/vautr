## What to build

Mobile platform integration (iOS/Android) that:
- On first MP unlock, generates a hardware‑backed key (Secure Enclave / TEE) requiring biometric authentication.
- Wraps the SVK using this hardware key, stores `WrappedSVK_Biometric` in `SharedPreferences`/`UserDefaults`.
- On subsequent unlocks, prompts biometrics (FaceID/TouchID), unwraps the SVK, and calls `core.unlock_with_raw_key`.
- If biometrics fail (e.g., 3 failures), fallback to Master Password.

## TDD Instructions

1. **Write a Kotlin test** (Android) that generates a hardware key, wraps a test SVK, then unwraps it with biometric authentication (mocked biometric success) – asserts the SVK matches.
2. **Write a Swift test** (iOS) that does the same using `LAContext` and `SecKey`.
3. **Write a test** that fails biometric authentication (simulate wrong finger or cancellation) – asserts fallback to MP prompt.
4. **Write a test** that after device reboot, the hardware key is still available and biometric unlock works (without re‑entering MP).
5. **Write a test** that if the user disables biometrics in OS settings, the app falls back to MP without error.

Implementation: on Android use `BiometricPrompt` + `KeyStore` (AES key with `setUserAuthenticationRequired`). On iOS use `LAContext` + `SecKeyCreateWithData` with `kSecAttrAccessibleWhenPasscodeSetThisDeviceOnly`.

## Acceptance criteria

- [ ] Biometric unlock works after app restart.
- [ ] The hardware key cannot be exported.
- [ ] Fallback to MP is seamless.
