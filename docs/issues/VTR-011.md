## What to build

A pure Rust function `derive_master_key(password: &Zeroizing<String>, salt: &[u8; 32]) -> Zeroizing<[u8; 32]>` in `vautr-crypto`. Uses Argon2id with parameters that can later be calibrated. No I/O, no side effects.

## TDD Instructions

1. **Write a test** that calls `derive_master_key` with a fixed password and zero salt; asserts output length is 32 bytes and not all zeros.
2. **Write a test** that calls the function twice with identical inputs and asserts the outputs are identical (deterministic).
3. **Write a test** that changes the password by one character and asserts the output is completely different (avalanche effect).
4. **Write a property‑based test** (using `proptest`) that generates random passwords and salts; asserts the output is always 32 bytes.

Implementation must use `argon2` crate with `Params::new(65536, 3, 4, Some(32))` for now. The salt is a fixed `[u8; 32]` passed as argument.

## Acceptance criteria

- [ ] All tests pass.
- [ ] The function is marked `#[must_use]`.
- [ ] No `println!` or logging of password or key.
