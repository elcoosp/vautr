## What to build

A client‑side PDF generator (using `printpdf` or `lopdf`) that:
- Takes the BIP‑39 24‑word mnemonic and the user’s email.
- Renders a clean, printable page with: Vautr logo, instructions (“Store in a safe place”), the 24 words in a numbered list, and a space for manual notation.
- **No QR code**, no machine‑readable representation.
- PDF is generated entirely in memory, never written to disk unless user explicitly saves.

## TDD Instructions

1. **Write a test** that generates a PDF for a known mnemonic, then parses the PDF text content and asserts all 24 words appear in order.
2. **Write a test** that verifies the PDF does **not** contain any image that could be a QR code (by scanning for QR code patterns or checking that no `(image)` object of type QR exists).
3. **Write a test** that ensures the PDF is not saved to disk automatically – the user must click “Save” and choose a location.
4. **Write a test** that the PDF generation time is < 500 ms for typical hardware.
5. **Write a test** that the PDF is not transmitted over the network (mock network and assert no requests).

Implementation: use `printpdf` with a template layout. The words are rendered as text elements, not as a barcode.

## Acceptance criteria

- [ ] The PDF contains only human‑readable words.
- [ ] No QR code, no base64‑encoded image that could be scanned.
- [ ] The PDF can be opened with any standard PDF viewer.
