## What to build

Create the directory structure and configuration files:
- Root `package.json` with Turborepo.
- `core/Cargo.toml` as a Rust workspace with empty member crates.
- `apps/` and `packages/` folders.

## TDD Instructions

This issue has no runtime tests – it’s infrastructure. Verification is manual:

1. Run `pnpm install` – must succeed without errors.
2. Run `cargo check --workspace` – all empty crates must compile.
3. Verify that `pnpm dev` starts a Turborepo pipeline (even if no tasks).
4. Ensure the directory layout matches `build-env-deploy.md`.

## Acceptance criteria

- [ ] `pnpm install` exits 0.
- [ ] `cargo check --workspace` exits 0.
- [ ] `apps/`, `packages/`, and `core/` exist with expected subdirectories.
