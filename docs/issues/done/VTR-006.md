## What to build

In `vautr-crypto`, define enums `DataSuite`, `SharingSuite`, `KDFSuite` with associated integer IDs. Provide `fn is_supported(id: u8) -> bool` and `fn active_*() -> Self` for each.

## TDD Instructions

1. **Write a test** that asserts `DataSuite::try_from(0x01).unwrap()` is `XChaCha20Poly1305`.
2. **Write a test** that calls `is_supported(0x01)` for each suite – must return `true`.
3. **Write a test** that calls `is_supported(0xff)` – returns `false`.
4. **Write a test** that checks `active_data_suite()` returns `XChaCha20Poly1305`.

Implementation: define enums with `#[repr(u8)]` and implement `From<u8>` and `TryFrom<u8>`. No encryption logic – only type definitions.

## Acceptance criteria

- [ ] All tests pass.
- [ ] No external dependencies except `core` (no `std` if possible).
- [ ] `active_sharing_suite()` returns `X25519`.
