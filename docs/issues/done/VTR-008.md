## What to build

GitHub Actions workflow (`.github/workflows/ci.yml`) that runs `pnpm lint:biome` (with `noConsoleLog` rule), `cargo fmt --check`, `cargo clippy --all-targets -D warnings`, `cargo test` (empty for now), and `pnpm typecheck`.

## TDD Instructions

This is configuration – verification is manual:

1. Push a dummy PR and observe the CI run – all steps must pass (green).
2. Introduce a `console.log` in a TS file – CI must fail.
3. Introduce a `unused_variable` in Rust – `clippy` must fail.
4. Remove a type annotation – `typecheck` must fail.

Implementation: write the YAML workflow with appropriate matrix (Rust stable, Node 20). Cache `target/` and `node_modules`.

## Acceptance criteria

- [ ] CI runs on every PR.
- [ ] `noConsoleLog` blocks any `console.*` in `apps/` or `packages/`.
- [ ] `cargo clippy` has `-D warnings`.
- [ ] The `test-instrumentation` feature is defined in root `Cargo.toml`.
