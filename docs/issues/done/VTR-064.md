## What was built

Brought the extension popup to parity with web for the four surfaces.

### Conflict modal (VTR-056)
- `apps/extension/src/popup/store.ts`: added `conflictQueue: ConflictEvent[]`
  + `pushConflict` / `dismissConflict` actions (FIFO, head = current).
- `apps/extension/src/popup/App.tsx`: `onVaultUpdate` now also routes
  `ConflictDetected` events from the client `subscribe` into `pushConflict`.
- `apps/extension/src/popup/components/ConflictModal.tsx`: ported the web
  `ConflictModal` (Radix-free, uses the extension's base-ui `Dialog`). Renders
  the head of the queue, dispatches `client.resolveConflict(uuid, choice)`, then
  `dismissConflict`. One at a time (no overlap); close-without-choice dismisses.
  Mounted in `App` when unlocked.

### Import / export (VTR-039)
- Added `backupStatus` / `backupExport` / `backupRestore` to the shared
  `VautrMlpClient` (`packages/vautr-client-sdk/src/mlp.ts`) — they previously
  only existed in the web app's own `mlp.ts`. Now reusable by both clients.
- `apps/extension/src/popup/components/ImportExportTab.tsx`: backup status,
  export (include-secrets toggle), restore-from-base64.

### Machine accounts + tokens (VTR-047)
- `apps/extension/src/components/ui/checkbox.tsx`: added a base-ui `Checkbox`
  primitive (mirrors the existing base-ui `Switch` style).
- `apps/extension/src/popup/components/MachineAccountsTab.tsx`: list / create
  (scope picker) / enable-disable / delete.
- `apps/extension/src/popup/components/TokensTab.tsx`: list / create (scope
  picker) / one-time secret display + copy / revoke.

### Wiring
- `App.tsx`: added `Backup` / `Machines` / `Tokens` tabs to the nav + content,
  gated on the `mlp` client.

  tokens, all of which are now met.
