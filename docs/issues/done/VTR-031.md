## What to build

A GPUI‑based desktop application (Rust) that:
- Uses `vautr-app-state` with the `desktop-api` feature flag enabled.
- Implements a native window with list view, detail view, and settings.
- Calls `read_secret(handle)` directly (allowed on desktop) to render secret text without FFI.
- Integrates with the OS file system for attachment import/export (e.g., picking a file for attachment).

## TDD Instructions

1. **Write an integration test** (using `gpui::test`) that simulates unlocking the vault, selecting an item, and clicking “Copy” – assert the system clipboard receives the password.
2. **Write a test** that creates a new item with a file attachment (using OS file picker mock), encrypts it via the streaming pipeline, and verifies the attachment appears in the item detail.
3. **Write a test** that exports an item to a `.json` file (plaintext) and asserts the file contains the decrypted overview (no secret).
4. **Write a test** that locks the vault after inactivity (using mocked time) and verifies the UI transitions to the lock screen and clears all rendered secrets.
5. **Write a property‑based test** that randomly creates, edits, and deletes items while the vault is locked/unlocked – no crashes or memory leaks (valgrind or heaptrack).

Implementation: use GPUI’s `App` and `Window` APIs. The `read_secret` call must be wrapped in a `#[cfg(feature = "desktop-api")]` block.

## Acceptance criteria

- [ ] The desktop binary compiles with `--features desktop-api`.
- [ ] `read_secret` is never called on non‑desktop builds (checked by CI symbol script).
- [ ] File picker integration works on Windows, macOS, and Linux (using `rfd` crate).
