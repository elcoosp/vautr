## What to build

A script `scripts/check-ffi-symbols.sh` that builds `vautr-wasm` and UniFFI bindings, then checks that the symbol `read_secret` is **not** present in the Web/WASM and mobile artifacts. Integrate into CI.

## TDD Instructions

Because this is a build script, write shell‑level tests:

1. **Write a “happy path” test** – after a correct build, the script exits 0.
2. **Write a “failing” test** – temporarily add a `#[no_mangle] pub extern "C" fn read_secret() {}` to `vautr-wasm`; the script must exit non‑zero.
3. **Write a test** that runs the script on the mobile FFI (dry‑run) and expects success.

Implementation: use `wasm-objdump` or `nm` to scan the compiled `.wasm` and `.a` files for the symbol name. Fail if found.

## Acceptance criteria

- [ ] `./scripts/check-ffi-symbols.sh` returns 0 when built correctly.
- [ ] The script is called in CI.
- [ ] Documentation added in `CONTRIBUTING.md`.
