## What to build

Two functions in `vautr-crypto`:
- `aead_encrypt(key: &[u8; 32], plaintext: &Zeroizing<Vec<u8>>, ad: &[u8]) -> Result<(Vec<u8>, [u8; 24]), CryptoError>`
- `aead_decrypt(key: &[u8; 32], ciphertext: &[u8], nonce: &[u8; 24], ad: &[u8]) -> Result<Zeroizing<Vec<u8>>, CryptoError>`

Uses XChaCha20-Poly1305 with 24‑byte random nonce for encryption.

## TDD Instructions

1. **Write a test** that encrypts a known plaintext, then decrypts with the same key and AD; asserts returned plaintext matches original.
2. **Write a test** that encrypts with wrong AD (one byte different) and asserts decryption fails with `CryptoError::TagMismatch`.
3. **Write a test** that corrupts a single byte of ciphertext and expects `TagMismatch`.
4. **Write a test** that encrypts an empty plaintext; asserts decryption succeeds and returns empty `Zeroizing<Vec<u8>>`.
5. **Write a property‑based test** that round‑trips random plaintexts and random AD.

Implementation must generate a fresh random nonce for each encryption (using `OsRng`). Decryption must verify the tag and return appropriate error.

## Acceptance criteria

- [ ] All tests pass.
- [ ] The nonce is never reused for the same key across test runs.
- [ ] `CryptoError::TagMismatch` is returned for corrupted inputs, not a panic.
