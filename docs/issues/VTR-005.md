## What to build

`vautr-app-state` crate containing `pub struct VautrClient` and methods from `client.md` (unlock, lock, search, reveal_secret, perform_action, release_secret, save_item, delete_item, watch_state). All methods return `Err(CoreError::NotImplemented)` – no `todo!()`. Use `#[cfg(feature = "desktop-api")]` to gate `read_secret`.

## TDD Instructions

1. **Write a test** that creates `VautrClient::new()` and calls `unlock_with_password` – must return `Err(CoreError::NotImplemented)` (not panic).
2. **Write a compile‑fail test** that attempts to call `read_secret` in a build without `desktop-api` feature – must fail compilation.
3. **Write a test** that subscribes to `watch_state` and checks that the channel is initially empty.

Implementation: provide empty stubs returning the error. The `watch_state` method should return a `tokio::sync::broadcast::Receiver` (create a channel but never send).

## Acceptance criteria

- [ ] `cargo test -p vautr-app-state` passes.
- [ ] No `todo!()` or `unimplemented!()` – only `return Err(...)`.
- [ ] `read_secret` is invisible when `desktop-api` is off.
