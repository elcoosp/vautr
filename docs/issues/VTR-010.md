## What to build

A `docker-compose.yml` that runs the `vautr-server` in development mode (hot reload), a SQLite volume, and an optional admin interface. The server must serve the OpenAPI spec at `/openapi.json` and respond to stub endpoints.

## TDD Instructions

Verification is manual:

1. Run `docker compose up` – no errors, server listening on port 8080.
2. `curl http://localhost:8080/openapi.json` – returns valid JSON matching the OpenAPI spec.
3. `curl -X GET http://localhost:8080/sync/pull?cursor=0` – returns 501 (or 404 if handler not yet implemented) but does **not** crash.
4. Modify a Rust file and observe that the server automatically restarts (hot reload).

Implementation: write `Dockerfile` for the server, `docker-compose.yml` with volume mount for source code and `cargo watch`. Use environment variables for configuration.

## Acceptance criteria

- [ ] One‑command startup works.
- [ ] SQLite file persists in `./data` directory.
- [ ] The server respects `RUST_LOG=debug` for tracing.
