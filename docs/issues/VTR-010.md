## What to build

A `docker-compose.yml` that runs the `vautr-server` in development mode (hot reload), a SQLite volume, and an optional admin interface. The server must serve the OpenAPI spec at `/openapi.json` and respond to stub endpoints.

## TDD Instructions

Verification is manual:

1. Run `docker compose up` – no errors, server listening on port 8080.
2. `curl http://localhost:8080/openapi.json` – returns valid JSON matching the OpenAPI spec.
3. `curl -X GET http://localhost:8080/sync/pull?cursor=0` – returns 501 (or 404 if handler not yet implemented) but does **not** crash.
4. Modify a Rust file and observe that the server automatically restarts (hot reload).

Implementation: write `Dockerfile` for the server, `docker-compose.yml` with volume mount for source code and `cargo watch`. Use environment variables for configuration.

## Acceptance criteria

- [x] One-command startup works. (`docker compose up -d --build` brings up `server` on :8080)
- [x] SQLite file persists in `./data` directory. (compose mounts named volume `serverdata:/data`; `VAUTR_DB_URL=sqlite:/data/vautr.db`)
- [x] The server respects `RUST_LOG=debug` for tracing. (compose passes `RUST_LOG: ${RUST_LOG:-info}`; main.rs uses `EnvFilter::from_default_env()`; `dev` profile defaults to `debug`)
- [x] `GET /openapi.json` returns the OpenAPI 3 contract. (server embeds `packages/api-contract/openapi.json` via `include_str!` and serves it at `/openapi.json`; unit test `openapi_spec_is_valid_json` guards the embedded doc)
- [x] Hot-reload dev mode. (`docker compose --profile dev up` runs `cargo watch` over a bind-mounted source tree; editing a Rust file recompiles + restarts the server — TDD #4)

## Notes

- `Dockerfile` (release, multi-stage, non-root `vautr` user, healthcheck on `/account/status`), `Dockerfile.dev` (cargo-watch hot reload), `docker-compose.yml` (server + opt-in `postgres` + opt-in `https` Caddy profiles), `.dockerignore`, and `deploy/Caddyfile` already existed; this pass added the `/openapi.json` route + embedded spec, the `dev` profile/service, and fixed a `VAUTR_DOMAIN` interpolation that blocked `docker compose config`.
