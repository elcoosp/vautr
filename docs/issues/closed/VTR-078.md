# VTR-078 — True element-anchored tour (mobile + desktop)

VTR-077 shipped the feature tour as *centered-card sequences* on mobile (RN) and
desktop (GPUI) because neither framework exposes an element-measurement
primitive the way web/extension do (`getBoundingClientRect` + `[data-tour]`).

This follow-up upgraded those two clients to **true spotlight anchoring**:

- **Mobile (RN):** the tour is now mounted as an overlay layer on top of the
  live app (in `RootLayout`), and target controls register their host `ref`
  through a `TourAnchor` wrapper (stable ids `secrets-tab`, `settings-tab`,
  `mfa-tab`). `TourOverlay` reads the registered ref and calls `ref.measure(...)`
  to get the real on-screen rect, then draws a dim scrim + highlight ring +
  positioned card next to the actual control. Steps without a live anchor fall
  back to a centered card. Implemented in `apps/mobile/src/tour/{anchors,TourOverlay}.tsx`
  and `steps.ts`, wired in `routes/_app.tsx` + `routes/__root.tsx`.
- **Desktop (GPUI):** the tour is no longer an early-return that hides the app —
  it renders as an overlay *on top of* the still-mounted view. A `canvas`
  element laid over the active section's content surface captures its
  post-layout `Bounds` via `on_prepaint` (the GPUI analogue of
  `getBoundingClientRect`); the card + accent highlight ring are positioned
  from those measured bounds. `render_tour` switches `self.section` per step so
  the anchored feature is on-screen behind the dimmed scrim. Implemented in
  `apps/desktop/src/desktop_view.rs` (`render`, `render_app` canvas measurement,
  `render_tour`) + `tour.rs` step `section` ids + `Section::from_tour_id`.

The shared step contract stays `docs/onboarding/tour.md`. The centered-card path
remains the graceful fallback if measurement is unavailable (mobile steps whose
anchor isn't mounted).

## Acceptance
- Mobile + desktop tours highlight the actual target surface, not a blind centered card.
- Skip / Back / Next / Finish still work; replay affordance unchanged.
- `hermes verify` green; `cargo test` / `tsc` / `cargo fmt --check` / `pnpm lint` clean.
