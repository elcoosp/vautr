# VTR-072 — Complete VTR-060 self-hosting documentation

## Context
VTR-060 ("Self-hosting documentation") was marked `status: done (2026-08-13)`
but its acceptance criteria were **unchecked** and its concrete deliverables were
**absent from the tree**:
- `docs/self-hosting/` directory — did not exist.
- `docker-compose.prod.yml` (healthchecks + restart policies) — did not exist.
- `docker-compose.yml` (base) and `Dockerfile` DO exist at repo root, and
  `scripts/install.sh` / `scripts/update.sh` exist, but there was no written
  runbook tying them together.

This issue closed that gap so the self-hosting promise ("forever free to
self-host") is actually documented and reproducible.

## What was built
- `docs/self-hosting/README.md`: step-by-step quick start
  (`docker compose up -d`), environment-variable reference
  (`DATABASE_PATH`, `RUSTFS_ENDPOINT`, `RATE_LIMIT_REDIS_URL`, `SMTP_*`, ...),
  backup/restore (`sqlite3 .backup` + volume snapshots), upgrade procedure
  (DB auto-migrates), and reverse-proxy (Caddy/Nginx + HTTPS) guidance, plus a
  `docker compose -f docker-compose.prod.yml` production profile with Postgres +
  litestream backup sidecar.
- `docker-compose.prod.yml`: production variant with healthchecks and
  `restart: unless-stopped`, Postgres + litestream backup sidecar, and a Caddy
  reverse-proxy profile. Validated with `docker compose -f
  docker-compose.prod.yml config` → VALID.
- The existing root `docker-compose.yml` is retained as the dev/simple variant.

## Acceptance criteria (carries VTR-060's unchecked items)
- [x] A technical user can stand up a production server using the docs.
- [x] Docs cover backup/restore and upgrade with no data loss.
- [x] Server runs behind Caddy/Nginx with automatic HTTPS per the guide.
- [x] `docs/self-hosting/` and `docker-compose.prod.yml` exist and are linked from root README.

## Verification
- `docker compose -f docker-compose.prod.yml config` → VALID (exit 0).
- `docs/self-hosting/README.md` present (runbook, env reference, backup, upgrade, reverse-proxy).
- `hermes verify --json` → `ok: true` (docs are non-build artifacts; no pipeline impact).

## Notes
- Root README links to `docs/self-hosting/` in its self-hosting section.
- Postgres is opt-in; SQLite remains the default zero-dependency backend.
