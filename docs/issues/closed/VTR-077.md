# VTR-077 — Anchored feature-tour (product walkthrough)

A lightweight, replayable product walkthrough distinct from the first-run guided
**setup** (VTR-073/074/075). Walks the user through the main surfaces: Vault,
Add a secret, Emergency Kit, Audit log.

**Contract:** `docs/onboarding/tour.md`.

## Approach (best-fit per platform)
OnboardJS has no element-anchor/spotlight API, so the tour is a purpose-built
overlay, not the onboarding engine:
- **Web + extension (VTR-073-style React):** *anchored* tour. A `TourOverlay`
  finds the real `[data-tour]` element via `getBoundingClientRect()`, draws a
  dimmed scrim + highlight ring + a positioned card (Back / Next / Skip /
  Finish). Anchors: `vault`, `add-secret`, `emergency-kit`, `audit`.
- **Mobile (RN) + desktop (GPUI):** *centered-card sequence* (no element
  measurement primitive available). Same copy/steps/order as the anchored tour.
  True element anchoring on RN (`measure()`) / GPUI (`bounds()`) is a documented
  follow-up, not shipped here.

## Files
- `apps/web/src/tour/{steps.ts,TourOverlay.tsx}` + `data-tour` anchors in
  `_authed.tsx`, `VaultView.tsx`; Settings "Replay tour" button; mounted in `main.tsx`.
- `apps/extension/src/tour/{steps.ts,TourOverlay.tsx}` + `data-tour` on popup
  tabs + VaultTab "+ Add"; footer "Replay tour"; mounted in `main.tsx`.
- `apps/mobile/src/tour/{steps.ts,TourOverlay.tsx}` + Settings "Replay tour";
  mounted in `App.tsx`.
- `apps/desktop/src/tour.rs` + `tour_step` field, `render_tour`,
  `trigger_replay_tour`, Settings card; `pub mod tour` in `lib.rs`.
