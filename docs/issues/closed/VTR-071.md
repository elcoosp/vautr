# VTR-071 — Audit-log viewer + export in clients

## What was built
The server already exposed `GET /audit` (admin) backed by the `audit_log` table
(`core/vautr-server/src/handlers/audit.rs`, `repository::audit`, `AuditFilter`),
recording login/logout/account-deletion/key-rotation metadata (VTR-053). No
client surfaced it. This issue adds the missing client surfaces:

- **SDK** (`packages/vautr-client-sdk/src/mlp.ts`): added `auditList(query?:
  AuditListQuery): Promise<AuditEntry[]>` to the MLP client plus an
  `auditQueryString()` serializer. The `/audit` OpenAPI path + `AuditEntry` /
  `AuditListQuery` schemas were added to `packages/api-contract/openapi.json`
  (the contract was missing entirely) so `generate.mjs` emits the types into
  `packages/api-contract/src/generated.ts` and they survive regeneration.
- **Web** (`apps/web/src/routes/_authed/audit.tsx`): new "Security log" route
  (`/_authed/audit`) listing events (action, event_type, actor, timestamp) with a
  "Download JSON" button, wired into the `_authed` nav (`apps/web/src/routes/_authed.tsx`).
  Uses `mlp.auditList({ limit: 100, offset: 0 })` from `apps/web/src/lib/mlp.ts`.
- **Desktop** (`apps/desktop/src/desktop_view.rs`): added `do_export_audit()`
  (calls `ApiClient::audit_list`, writes the JSON to a file reusing
  `export_path_input`) and an "Export audit log (JSON)" card in
  `render_import_export`, mirroring the vault-export pattern. Backend call added
  to `apps/desktop/src/api_client.rs` (`audit_list`).

## Zero-knowledge note
Audit events are **metadata only** (who/what/when), never secret plaintext
(VTR-053). The export contains only `AuditEntry` fields (id, user_id, action,
actor, detail, created_at, event_type, resource_type, resource_id, ip_address) —
no decrypted secret bytes. ZK-safe by construction.

## Acceptance criteria
- [x] `mlp.auditList()` exists in the SDK and returns the `GET /audit` contract shape.
- [x] Web "Security log" lists events with pagination and offers JSON download.
- [x] Desktop "Security log" exports the audit timeline to a file (reuses the vault-export path input).
- [x] Export contains only metadata fields, no secret bytes.
- [x] `pnpm -r typecheck` and `hermes verify --json` stay green.

## Verification
- `cargo check -p vautr-desktop` → CHK=0 (real compiler, sccache disabled).
- `cargo check --workspace` → CHK=0.

- The `/audit` path + `AuditEntry`/`AuditListQuery` types are now generated from
