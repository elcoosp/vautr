# VTR-075 — First-run guided onboarding (desktop)

**Goal.** Same onboarding *result* on the **desktop** (Rust/GPUI) client: the 5
steps from `docs/onboarding/spec.md`, first-run-once, and a replay affordance.

**Approach (chosen: "native Rust port — onboardjs cannot run in Rust").**
`desktop_view.rs` is a 6000-line GPUI view; OnboardJS is a JS/React library and
cannot execute inside the Rust process. Embedding a webview only for onboarding
would break the native feel and the zero-knowledge stance. So this is a faithful
**re-implementation of the flow** (not the engine):
- `apps/desktop/src/onboarding.rs` — `OnboardingStep` data (same copy/order,
  skippable flags per spec) + first-run persistence to
  `~/.config/vautr/onboarding.json` (`seen_v1` flag). `load_seen()` /
  `mark_seen()`.
- `apps/desktop/src/desktop_view.rs` — `onboarding_step: Option<usize>` field;
  `render()` early-returns `render_onboarding` when active (full-window GPUI modal
  using the existing `absolute().inset_0()` + `theme.rs` tokens, matching the
  create-project modal idiom). `render_onboarding` drives Back / Next / Skip /
  Finish; the create-vault step defaults the name and calls the canonical
  `do_create_project`; Emergency Kit / add-secret map to `Section::Mfa` /
  `Section::Vault` via `activate_section`. `trigger_replay_onboarding` restarts
  step 0 from Settings (card added in `render_settings`).

**Persistence.** `~/.config/vautr/onboarding.json` (`{ seen_v1: true }`) — a tiny
std::fs + serde file. First-run-once enforced in `DesktopView::new()`
(`Some(0)` only when `!load_seen()`).

**Verification.**
- `cargo check` (desktop) — clean (sccache disabled; the LSP E0670 "async move"
  noise is the known Rust-2015-on-2024-crate false-positive, not a real error).
- `cargo fmt --check` (desktop) — clean.
- `hermes verify --json` → `ok: True` (full workspace green, incl. the cargo test
  phase).

**Files.** `apps/desktop/src/onboarding.rs`, `apps/desktop/src/desktop_view.rs`
(`onboarding_step` field + `render_onboarding`/`do_onboarding_create_vault`/
`trigger_replay_onboarding` + Settings card), `apps/desktop/src/lib.rs` (`pub mod
onboarding`), `apps/desktop/Cargo.toml` (serde/serde_json already present). Docs:
`docs/onboarding/spec.md`, `docs/issues/closed/VTR-075.md`.
