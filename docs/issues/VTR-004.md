## What to build

Use `openapi-typescript` to generate Zod schemas and TypeScript types into `packages/api-contract/`. Then generate Axum handler stubs (e.g., using `oapi-codegen` or manual templates) that return `501 Not Implemented`.

## TDD Instructions

1. **Write a type test** (in TypeScript) that imports the generated types and asserts that an object matching the `SyncPullResponse` schema compiles without errors.
2. **Write an integration test** (Rust) that starts a test server with the stubs and calls `GET /sync/pull?cursor=0` – must return 501 with a JSON body `{"error":"not_implemented"}`.
3. **Write a negative test** that calls a non‑existent endpoint – must return 404.

Implementation: run `pnpm generate:api` script to create types; write a small code generator or manually stub the Axum handlers.

## Acceptance criteria

- [ ] `pnpm typecheck` passes.
- [ ] `cargo test -p vautr-server` passes (stub tests).
- [ ] Generated types match the OpenAPI spec exactly (no drift).
