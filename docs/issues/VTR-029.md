## What to build

Web application (React + Vite) that:
- Spawns a Web Worker running the WASM `VautrClient`.
- Communicates via `postMessage` using typed messages (actions and responses).
- Implements the `PlatformAdapter` trait for clipboard copy: when `CoreAction::CopyToClipboard` arrives, the main thread executes `navigator.clipboard.writeText`.
- The secret string never enters the React component state; only the handle is passed.

## TDD Instructions

1. **Write a Playwright test** that clicks “Copy password” on a masked field, then uses `page.evaluate` to read clipboard and asserts the correct password.
2. **Write a test** that reveals a password (eye icon), asserts the `<secret-view>` web component shows the plaintext, and after navigation, the handle is released (check via `release_secret` call in the worker).
3. **Write a test** that searches for “bank” and verifies the list updates within 100ms.
4. **Write a test** that simulates a worker crash (terminate worker) and checks the UI re‑spawns a new worker and re‑loads state.
5. **Write a performance test** that copies 100 passwords sequentially and measures average time < 50ms per copy.

Implementation: use `comlink` or custom `postMessage` serialization. The React app only holds the handle as a string (u64) in a ref, never the secret.

## Acceptance criteria

- [ ] No secret string appears in Chrome DevTools (search logs, React DevTools).
- [ ] The worker is terminated when the tab is closed.
- [ ] Clipboard write succeeds even if the user navigates away before the promise resolves.
